Đang kiểm tra môi trường kết nối…

Máy chủ cục bộ chưa có tài khoản Admin. Hãy tạo tài khoản trong terminal rồi bấm kiểm tra lại:

npm run admin:setup

Hoặc đặt biến môi trường ADMIN_USER và ADMIN_PASS trước khi chạy npm run admin.

Trang đang chạy dưới dạng tĩnh (GitHub Pages). Đăng nhập bằng GitHub Fine-grained PAT có quyền ghi vào kho mã nguồn để mở khóa và commit chỉnh sửa trực tiếp.

Cách tạo GitHub Token an toàn (chỉ cấp quyền cho repo này)
  1. Vào GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Ở mục Repository access, chọn Only select repositories → chọn kho này.
  3. Ở Repository permissions, đặt Contents: Read and write.
  4. Token chỉ lưu trong sessionStorage của tab trình duyệt hiện tại và tự xóa khi đóng tab hoặc bấm Đăng xuất.
